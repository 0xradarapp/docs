2. Description of Service

0xRadar is a multi-chain cryptocurrency wallet intelligence platform that provides:

  • Portfolio tracking — aggregated view of token balances and NFT counts across multiple blockchain networks.
  • DeFi position monitoring — tracking of lending protocol positions, health factors, and liquidation risk.
  • Alerts — Telegram-based notifications for liquidation risk, health factor thresholds, and other wallet events.

  • API access — programmatic access to wallet intelligence data via REST API and SDKs.
